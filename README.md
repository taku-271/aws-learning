# aws-learning

AWSの学習内容を整理するためのリポジトリです。学習するトピック(サービスや概念)ごとにディレクトリを作成し、その中にまとめ・CDKコード・Terraformコードなどを配置していきます。

## ディレクトリ構成

トピックごとに以下の構成でディレクトリを作成します。

```
<番号>-<トピック名>/
├── README.md      # 学習内容のまとめ(概要、ハンズオン手順、参考リンクなど)
├── cdk/           # AWS CDKで書いた構築コード(該当する場合)
├── terraform/     # Terraformで書いた構築コード(該当する場合)
└── site/          # 公開サイト用ページ(該当する場合。下記「サイト公開」参照)
```

例:

```
01-vpc/
├── README.md
├── cdk/
└── terraform/
02-iam/
├── README.md
└── terraform/
```

- 番号はトピックを学習した順序を表します。
- `cdk/`・`terraform/`はそのトピックで実際に構築コードを書いた場合のみ作成します(両方作る場合・片方だけの場合どちらもあり)。

## サイト公開

各トピックに `site/index.html`(+ 好きなだけCSSなど)を手書きで用意すると、それを1つの静的HTMLサイトに
まとめて公開できる仕組みを `site/` に用意しています。README.mdの自動変換ではなく、公開したいトピック
ごとに個別デザインのページを作る方式です。CloudFront + S3(AWS Blocksでホスティング)で誰でも閲覧できる
URLを発行できます。詳細は [site/README.md](site/README.md) を参照してください。
