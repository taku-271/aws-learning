# aws-learning

AWSの学習内容を整理するためのリポジトリです。学習するトピック(サービスや概念)ごとにディレクトリを作成し、その中にまとめ・CDKコード・Terraformコードなどを配置していきます。

## ディレクトリ構成

トピックごとに以下の構成でディレクトリを作成します。

```
<番号>-<トピック名>/
├── README.md      # 学習内容のまとめ(概要、ハンズオン手順、参考リンクなど)
├── cdk/           # AWS CDKで書いた構築コード(該当する場合)
└── terraform/     # Terraformで書いた構築コード(該当する場合)
```

例:

```
01-vpc/
├── README.md
├── cdk/
└── terraform/
02-iam/
├── README.md
└── terraform/
```

- 番号はトピックを学習した順序を表します。
- `cdk/`・`terraform/`はそのトピックで実際に構築コードを書いた場合のみ作成します(両方作る場合・片方だけの場合どちらもあり)。

## サイト公開

各トピックの `README.md` を、そのまま静的HTMLサイトとして公開する仕組みを `site/` に用意しています。
CloudFront + S3(AWS Blocksでホスティング)で誰でも閲覧できるURLを発行できます。詳細は
[site/README.md](site/README.md) を参照してください。
